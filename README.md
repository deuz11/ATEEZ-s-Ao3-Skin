# How to Add Custom CSS to an AO3 Site Skin

This guide explains how to take custom CSS code and apply it as a Site Skin on **Archive of Our Own (AO3)**. You can use this method to change fonts, colors, layouts, and overall aesthetics while browsing the archive.

---

## Prerequisites

* An active **AO3 account**.
* Your custom CSS code ready to copy and paste.

---

## Step-by-Step Instructions

### Step 1: Navigate to Your Skins
1. Log into your AO3 account.
2. Go to your **Dashboard** by clicking your username in the top right.
3. In the sidebar menu, click on **Skins**.

### Step 2: Create a New Site Skin
1. On the Skins page, click the **[Create Site Skin]** button at the top.
2. Fill out the basic information for your skin:
   * **Title:** Give your skin a clear, recognizable name (e.g., `My Custom Dark Mode`).
   * **Description:** *(Optional)* Briefly describe what the skin does.
   * **Colors:** Leave these default or select a base skin (like "Default") if your CSS builds on top of it.

### Step 3: Add Your CSS Code
1. Scroll down to the **CSS** text box area.
2. Copy your custom CSS code and paste it directly into the large text box.

### Step 4: Save and Apply
1. Scroll to the bottom of the page and click the **[Save]** button.
2. Once saved, you will be taken to your new skin's preview page. 
3. Click the **[Use]** button at the top to activate the skin on your account.

---

## Troubleshooting & Tips

* **Invalid CSS:** If AO3 throws an error upon saving, check your code for unsupported selectors or syntax errors. AO3 uses a sanitized version of CSS.
* **Updating the Skin:** If you make changes to your CSS later, go to **Skins > Your Skins**, click **[Edit]** on your skin, update the code in the CSS box, and click **[Update]**.
